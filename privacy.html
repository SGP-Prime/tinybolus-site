TinyBolus Privacy Policy

Last updated: 8 July 2026

What data we collect

None. TinyBolus does not collect, store, or transmit any patient data. Patient age and weight values entered into the application are processed locally on your device and are not retained after the session ends. No user account, login, or network connection is required for core functionality.

Network activity

The application fetches formulary updates from a secure server (raw.githubusercontent.com) when launched and when internet connectivity is available. The update mechanism is one-way: the device requests the formulary file and receives it. No user or patient data is included in the request.

That server is operated by GitHub, Inc. (United States). As with any web request, GitHub's infrastructure necessarily sees your device's IP address and basic technical request metadata when the update is fetched; this is inherent to how the internet works, is not linked by us to any person, and is the only third-party contact the application makes. GitHub's own privacy statement governs its handling of server logs. If you use the application entirely offline, no network request occurs at all.

Analytics, telemetry, and crash reporting

None. TinyBolus performs no analytics, crash reporting, or usage tracking without explicit user opt-in. As of this version, no such opt-in mechanism exists in the application.

Children's privacy

TinyBolus is a clinical reference tool intended for use by qualified medical professionals. It is not directed to or intended for use by children. Patient values entered by a clinician describe a patient's age and weight; the application does not associate this information with any identifiable child and does not retain it.

Data controller & your rights (GDPR)

TinyBolus is provided by Aether Somnus, Lda. (Portugal), which is the data controller for the application. Because the app itself collects and stores no personal data, there is ordinarily no personal data held by us to access, rectify, erase, or port on request. If you contact us by email, we will hold that correspondence (your address and message); you may request access to or erasure of it at any time using the contact below. If you have any question about data protection, or believe the app processes data contrary to this policy, contact us using the details below. You also have the right to lodge a complaint with the Portuguese supervisory authority (Comissão Nacional de Proteção de Dados, CNPD).

Changes to this policy

If this policy changes in any material way, the updated version will be posted here with a revised effective date. The version of the policy in effect at the time you use the application governs.
